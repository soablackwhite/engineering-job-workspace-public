# Synthetic browser rehearsal

The CUA bridge and fixture pages support isolated protocol tests. Fixtures are synthetic, temporary and unrelated to real accounts. Run Node/Python checks from the root README; do not launch a real application session as a test prerequisite.

Rehearsal evidence is distinct from production evidence. A mock chooser, local download, receipt-shaped fixture or stored filename cannot prove that an employer received a real CV. Actual uploads require explicit operator scope, approved private artifact verification and visible fresh browser evidence.

Keep screenshots, chooser paths, file downloads and checkpoint evidence in ignored private runtime storage. Export only generic fixture source. Do not include a personal home directory or a previously downloaded CV in examples.
